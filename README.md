# CSE226: Android App Deployment

This repository contains the coursework and implementation for the **CSE226: Android App Deployment** course.

## 📚 Syllabus Overview

### Unit I: Advanced Jetpack Compose UI Development
- **Material 3 Components:** Bottom Sheets, Dialogs and Alert Dialogs.
- **Side Effects:** LaunchedEffect, DisposableEffect, SideEffect.
- **Animations:** Compose Animation APIs.
- **Design Patterns:** Custom Composable Design Patterns.
- **Optimization:** UI Performance Optimization, Responsive UI Development.

### Unit II: Kotlin Coroutines and Reactive Programming
- **Basics:** Coroutine Scopes, Context, Dispatchers, Structured Concurrency.
- **Operations:** Suspending Functions, Cancellation, Timeouts, Exception Handling.
- **Reactive Streams:** Flow, StateFlow, SharedFlow, Flow Operators.
- **Integration:** Coroutines with Compose.

### Unit III: Android Architecture Components
- **MVVM Architecture:** ViewModel, Lifecycle-Aware Components.
- **State Management:** State Hoisting, SavedStateHandle.
- **Patterns:** Repository Pattern, Single Source of Truth.
- **Business Logic:** UI State and Business State Management.

### Unit IV: Local Data Persistence and Offline Storage
- **Room Database:** Architecture, Entities, DAOs, Relationships.
- **Advanced Room:** Type Converters, Database Migration, Room with Flow.
- **Strategy:** Data Synchronization, Offline-First Application Development.

### Unit V: Location-Based Android Applications
- **Permissions:** Runtime Permissions.
- **Fused Location:** Location Updates, Geocoding, Reverse Geocoding.
- **Maps:** Google Maps Compose, Markers, Map Customization.
- **Services:** Integration of Location Services with Local Data.

### Unit VI: Version Control, Debugging and Application Quality
- **Quality:** Android Application Quality.
- **Testing:** Unit Testing (JUnit), Jetpack Compose UI Testing.
- **Debugging:** Logcat, Android Studio Debugger, Crash Analysis.
- **Git/GitHub:** Git Fundamentals, Repository Management, Branching, Merging, Pull Requests, Conflict Resolution, Collaborative Workflows.
